# Contributing

Corrections to the notes, synthetic test cases and improvements to the read-only inspection utility are welcome.

Please include your OS, Python version and a short description of the failure when reporting an inspection problem. Redact personal paths and device identifiers. Do not attach game archives, assets, screenshots containing private information, full device logs, private keys, decompiled proprietary code, download mirrors or purchase-unlock patches.

This project does not distribute the game or provide a working-build download. Contributions must be material you are authorized to share. Original contributions are submitted under this repository's MIT license.
