# Rights and publication scope

This project shares original diagnostic code and technical observations. An open-source license for those materials does not grant rights to the game being discussed.

Discontinuation or removal from a store is not evidence that a game has been placed in the public domain or that its owner has authorized redistribution. This investigation did not obtain such authorization.

GitHub prohibits infringement of third-party intellectual property and has a process for copyright complaints. Its policies also restrict unlawful sharing of certain license-circumvention tools. Publishing original notes with no game payload avoids distributing the payload, but is not a guarantee against a complaint or other legal risk.

The repository therefore excludes executable game files, proprietary assets, decompiled code, binary patches, purchase-unlock tools, mirrors, private keys and device logs. Contributors should supply original explanations and small, non-sensitive diagnostic excerpts only. Do not upload a game file to an issue.

The MIT license applies only to this repository's original material, to the extent copyright exists, and does not change third-party rights. Disney and game names are used solely to identify the subject of this independent investigation; no affiliation or endorsement is claimed. UnityPy and other third-party tools have their own licenses.

These are publication-scope notes, not legal advice. A copyright lawyer can assess a particular distribution proposal and jurisdiction.
